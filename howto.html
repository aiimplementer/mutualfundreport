How to Generate a Mutual Fund Portfolio Report from CAS

Upload your Mutual Fund CAS statement and generate a detailed portfolio report with performance, allocation and XIRR insights. See how your investments are performing, understand fund allocation, and review portfolio insights including overall XIRR and balance.

Generate Your Portfolio Report in 3 Simple Steps
Follow these steps to generate a detailed analysis of your mutual fund portfolio.
1
Download Your CAS & Save a Password-Free Copy

Download your Consolidated Account Statement (CAS) from CAMS or KFintech — select "Detailed (Includes transaction listing)" when generating it. If you don't have one yet, generate it here: Generate CAS →

CAS files are usually password protected. Open the file and save a password-free copy — press Ctrl + P (or right-click → Print) and choose "Save as PDF" to remove the password before uploading.

2
Upload the CAS File

Go to the Dashboard and upload the saved CAS PDF file. The maximum upload size is 20 MB.

3
Generate Your Portfolio Report

Choose the report type — such as My Portfolio View or Portfolio Overview. Your portfolio will be analysed and the report generated within seconds.

💡 Tip: You can generate multiple reports using the same uploaded CAS file to analyse your portfolio from different perspectives.
ℹ️ Note: Please ensure the CAS PDF is not password-protected, as protected files cannot be processed. Maximum file size is 20 MB.
